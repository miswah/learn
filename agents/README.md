# Subagent Definitions

This folder contains subagent definitions:

- **[`researcher.md`](researcher.md)**: Web researcher specializing in topic search, source validation, and concise briefing.
- **[`mermaid-maker.md`](mermaid-maker.md)**: Dedicated diagram creator for structural and relational visuals using Mermaid syntax.
- **[`svg-maker.md`](svg-maker.md)**: Spatial and geometric diagram author for coordinate geometry, vectors, and layouts using clean SVG.

These agents are integrated into Gemini via `GEMINI.md`, `AGENTS.md`, and `.agents/rules/agents.md`.
